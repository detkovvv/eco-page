# Историческая страница ЭКО

Статическая страница вебинара 2020 года. Текст и предложения сохранены как часть исторического кейса; поддерживается вёрстка и адаптивность.

Откройте `index.html` или запустите любой локальный статический сервер в корне репозитория.

После публикации страница доступна по адресу: https://detkovvv.github.io/eco-page/.

GitHub Pages обновляется workflow `.github/workflows/deploy.yml` при изменении ветки `master`.
